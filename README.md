# qa_python
 | № | Имя теста                                           | Что проверяет                                                                                                                                                                            |
|---|-----------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1 | **test_add_new_book_add_two_books**                 | Проверяет добавление двух книг в коллекцию. Убедимся, что количество книг в словаре `books_genre` соответствует числу добавлений.                                                        |
| 2 | **test_set_book_genre_valid**                       | Проверяет установку допустимого жанра книге. После вызова метода `set_book_genre` книга должна получить указанный жанр.                                                                  |
| 3 | **test_set_book_genre_invalid**                     | Проверяет установку недопустимого жанра. Если жанр не входит в список разрешённых, книга сохраняется с пустым жанром.                                                                    |
| 4 | **test_get_books_with_specific_genre_parametrized** | Параметризованный тест, проверяющий, что метод `get_books_with_specific_genre` возвращает корректный список книг по заданному жанру (включая случаи с пустыми или неизвестными жанрами). |
| 5 | **test_get_books_genre_not_empty**                      | Проверяет, что метод `get_books_genre` возвращает конкретный заданный словарь.
| 6 | **test_get_books_for_children_only_children**       | Проверяет, что метод `get_books_for_children` возвращает только книги, подходящие детям (исключая жанры с возрастным ограничением — «Ужасы» и «Детективы»).                              |
| 7 | **test_add_book_in_favorites_done**                 | Проверяет добавление книги в список избранного. Книга должна быть предварительно добавлена в коллекцию.                                                                                  |
| 8 | **test_delete_book_from_favorites_done**            | Проверяет удаление книги из избранного. После удаления список избранного должен быть пустым.                                                                                             |
| 9 | **test_get_list_of_favorites_books_done**           | Проверяет корректное получение текущего списка избранных книг. Метод должен возвращать актуальное содержимое списка `favorites`.
| 10 | **test_get_book_genre_return_correct_genre**           | проверяем работу метода `get_book_genre` по возврату жанра конкретной книги.
